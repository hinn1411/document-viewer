# T03: CI pipeline
P0 · est 1 h · done · 2026-10-29

**Why:** the gate for FR1–NFR6 → without it, unformatted or failing code reaches `main`.

## Done when
1. Given a PR, when CI runs, then `Format, build and test` runs `spotless:check` then `./mvnw -B verify`, passes and uploads test reports.
2. Given a PR with a badly formatted Java file, then the check fails at "Format check" and verify doesn't run.
3. Given a green non-draft PR, then the `Claude review` job posts inline comments only (no edits or pushes), replacing Claude's earlier ones. A red or draft PR gets no review.
4. Given protection on `main`, then a direct push, a force push or a merge without a green `Format, build and test` is refused.
