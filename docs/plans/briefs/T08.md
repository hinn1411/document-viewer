## Done when
1. Given the flat records response, when `fetch` runs, then `recordId` 778 becomes `id()` `SERVICE:778`, `completedAt` epoch seconds becomes a UTC `Instant`, and `category` maps (`JOB_CARD`, `MOT`, unknown → `OTHER`). Given `[]`, then the list is empty.
2. Given a record with no `recordId`, a `fileUrl` that isn't `https` or a `completedAt` outside `Instant`'s range, then that record is dropped and the others are kept. Given no `completedAt`, then it's kept undated.
3. Given a body that can't be parsed, isn't a list or has a null entry, then `fetch` throws `SourceException(ERROR)` with no retry. Given a 404, the same. The exception has no cause and no VIN.
4. Given 503 then 200, then it succeeds with 2 requests. Given 503 twice, then `ERROR` with 2 requests. Given a read longer than 1.5 s, then `TIMEOUT` with 1 request.
5. Given T08's diff, then `src/main/java` changes only under `source/service/`; `application.yml` gets the `service` entry.
