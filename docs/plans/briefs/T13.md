## Done when
1. Given a search where Service times out, then `docviewer_source_calls_total{source="SERVICE",result="timeout"}` and `docviewer_requests_total{outcome="partial",status="200"}` each go up by 1.
2. Given searches that include a fallback copy, then `/actuator/prometheus` exposes all six metrics, with buckets at 0.25, 0.5, 1, 2 and 2.5 s on both histograms, plus Spring's `http_client_requests` for the sources.
3. Given a failed audit, then `docviewer_audit_failures_total` and `docviewer_requests_total{outcome="failed",status="503"}` each go up by 1.
4. Given an open breaker, then `result="circuit_open"` goes up by 1.
5. Given a search, then `/actuator/prometheus` contains no full VIN.
6. Given `docker compose up`, the app running and a few demo requests, then Grafana shows the dashboard with data, Prometheus lists the app as up with all four alert rules loaded, and `promtool check rules observability/alerts.yml` passes.
